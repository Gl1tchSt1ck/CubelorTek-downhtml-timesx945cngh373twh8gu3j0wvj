# VoxelCraft (Minecraft‑Inspired Sandbox) Save this as `index.html` and open it in a browser. You can later package it into an APK using tools like Capacitor, Cordova, or an Android WebView wrapper. ```html VoxelCraft
+
WASD = Move
Mouse = Look
Space = Jump
Left Click = Remove Block
Right Click = Place Block
``` ## Turning It Into An APK 1. Put the file in a folder. 2. Use a wrapper like Capacitor or Cordova. 3. Build the Android app. 4. Rename the APK whatever you want. Suggested names: * VoxelCraft * BlockVerse * CubicRealms * MineGrid * TerraBlocks
